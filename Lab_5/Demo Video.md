## Build Instructions
- In the Lab 5 Dir run the following 
```bash

# Notes: Make sure to have CMake and Make installed 
# Locate the ipecmd.sh script and symlink it to ipecmd
# Add the symlink to your PATH variable.

# Build  
make build 

# Program the device
make prog

# Entire Flow
make # or make all

# To clean the build 
make clean
```
